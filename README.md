# ruso-diario

Aprende a leer ruso 10 minutos al día: alfabeto, sesiones con ejercicios, teclado cirílico,
repaso espaciado (FSRS) y panel de progreso.

Versión estática publicada en GitHub Pages: <https://alfonso-wav.github.io/ruso-diario/>.
El progreso se guarda en el navegador; desde «Progreso» se puede exportar e importar en JSON.

Este repositorio contiene solo el build (`vite build --mode pages`).
